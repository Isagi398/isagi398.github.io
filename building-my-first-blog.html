What I Learned While Building My First Blog With HTML and CSS

Published: September 4, 2026 • 2 min read

I recently started learning web development and decided that instead of only watching tutorials, I wanted to build something myself. My first project became a simple blog using HTML and CSS.

Why I Decided to Build a Blog

I wanted a project that could help me practice web development while also giving me a place to document what I learn.

The First Version Looked Very Simple

My first page contained only headings, paragraphs, and a few navigation links. It looked plain because I had not added CSS yet.

CSS Changed Everything

After adding CSS, I started understanding how spacing, width, fonts, backgrounds, and layouts affect the appearance of a webpage.

One Thing That Confused Me

One challenge was understanding how HTML and CSS connect. I learned that HTML creates the structure of the page, while CSS controls how that structure looks.

What I Learned

The biggest lesson was that building something myself helped me understand web development better than only watching tutorials.

What's Next?

My next goal is to continue improving this blog and start learning JavaScript so I can make the website more interactive.
