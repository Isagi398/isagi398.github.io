How I Discovered CSS While Experimenting With My First HTML Pages

Published: September 15, 2026

When I began my journey into HTML, it was a fun hobby for me. Initially, I spent many hours experimenting with HTML. I worked on adding in different images, writing various lines of text, changing things around, and observing what happened. Then, I thought to myself, “What if I could enhance the appearance of this?” At that moment, I was not really knowledgeable about how to go about this. This led me to search for information on how I could improve my UI, and this is how I stumbled upon CSS. That was when everything started getting interesting.

Why Not Just HTML?

At the beginning, I was like, "Can HTML not resize images?" Yes and no, since there are some ways it can. However, CSS allows you to have a much greater control over the design and layout of a web page. I could resize images with CSS, change font colors, control the space between one element and another, organize elements on my webpage, and the page would look completely different. It seemed to me like magic, compared to my plain HTML page. Moreover, there was another side to it.

Abundance of function in CSS

CSS is easy to learn, but it has a lot of properties and capabilities. The more I learned, the more complex it became. Occasionally, I would make a small error that would make my site look terrible on one machine or not appear at all! I surely couldn't remember every single property I worked with. At first, this upset me. Eventually I figured out the most important thing: I don't have to remember everything!

Most Enjoyable thing

Whenever a particular task comes up, I look for ways to accomplish it. I apply the method I find and get on with my work. However, I’m still learning and still get stuck sometimes. To be honest, I probably enjoyed the process of experimentation more than anything else. While it can sometimes be frustrating to be stuck, it’s lovely to finally see the solution working. So, the most important thing I’ve learned so far is: Stop being too obsessed with perfection. Instead, just do things, make mistakes, run into obstacles, search for solutions, and have fun along the way.

How I Enjoyed Experimenting With CSS

An aspect of learning CSS that I relished was the experimentation that came with it. I would add a CSS property to my page, refresh it, and see what happened. Sometimes, the output looked fantastic while at other times it looked silly.

To illustrate, I could start with a simple image and experiment with its appearance using CSS.

I could modify things such as color, size, positioning, and spacing simply by changing a few lines of CSS This was the best part for me as it wasn’t only learning some property but modifying something and seeing output right away. Occasionally, I would keep changing a value just to see where I could take the design. I wouldn’t know what I was doing each time, but that was the fun part about it.

What I Learned

Through my experience with CSS, I have come to understand that programming has more to it than simply memorizing every bit of information or writing perfect code. Initially, I thought that I had to remember everything that I learned; however, after working with CSS, I found that it is perfectly fine to forget properties or to be clueless about a certain problem. The most important thing is knowing how to figure things out.

I also realized that experimentation is one of my best methods of learning. It did not take long for me to understand CSS better when I tried to make some changes to the code, refresh the page, and see the result, as opposed to just reading about it. Besides, I have learned that mistakes are part of learning. It sometimes happens that one character or property is enough for making everything look wrong, but I stopped viewing it as a failure. The most important thing is that I have learned how to enjoy the process.

There might be occasions when coding appears to be simple, or occasions when a little problem can turn out to be incredibly irritating. Being stuck doesn’t mean that I am a lousy programmer. It usually simply means that something new is waiting to be discovered by me. I am still learning the art of CSS, and at this point not everything is stuck in my head. Nonetheless, I have realized that it is okay to forget some information and that it is not a big deal.

All I have to do now is experiment, learn, and build!
